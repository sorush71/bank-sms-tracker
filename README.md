# حسابدار پیامکی هوشمند (BankTracker)

اپلیکیشن اندرویدی برای مدیریت خودکار تراکنش‌های مالی و هزینه‌ها از طریق رهگیری پیامک‌های بانکی با پاپ‌آپ آنی و دسته‌بندی هوشمند.

## ویژگی‌های اصلی

۱. **رهگیری خودکار پیامک‌های بانکی:**
   - شناسایی هوشمند مبالغ واریز (`+`) و برداشت (`-`).
   - تبدیل خودکار مبالغ از ریال به تومان (حذف یک صفر).
   - نادیده گرفتن هوشمندانه شماره حساب‌ها، مانده موجودی و پیام‌های اطلاع‌رسانی/تبلیغاتی.
   - فیلتر سرشماره‌های بانکی از طریق لیست سفید (`Whitelist`) با امکان افزودن هر بانک دلخواه.

۲. **پاپ‌آپ آنی شناور روی صفحه (`Overlay Dialog`):**
   - به محض دریافت پیامک، پاپ‌آپ اختصاصی روی صفحه ظاهر شده و مبلغ، نوع تراکنش و بانک را نمایش می‌دهد.
   - فیلد متنی با قابلیت ساجست خودکار (`AutoComplete`)؛ با تایپ حرف اول (مثلاً «س»)، دسته‌بندی‌های قبلی نظیر «سیگار» پیشنهاد داده می‌شوند.
   - دکمه اختصاصی **«نادیده گرفتن»** برای انتقال بین حساب‌های خودتان.

۳. **داشبورد ماهانه با تقویم خورشیدی (جلالی):**
   - تفکیک ماه به ماه مخارج و درآمدها (آبان، آذر و...).
   - محاسبه خودکار تراز مالی ماه (مجموع واریزی‌ها - مجموع پرداختی‌ها).
   - نمودار و درصد سهم هر دسته از کل هزینه‌های ماه.
   - تاریخچه کامل تراکنش‌ها با قابلیت جستجو.

۴. **سیستم به‌روزرسانی درون‌برنامه‌ای (`GitHub In-App Updater`):**
   - بررسی خودکار نسخه جدید از ریپازیتوری گیت‌هاب بدون نیاز به فروشگاه‌های واسط.
   - دانلود و نصب مستقیم فایل APK از طریق `DownloadManager` و `FileProvider`.

۵. **بهینه‌سازی اختصاصی برای شیائومی و هایپراواس (`HyperOS / Android 15`):**
   - دسترسی مستقیم از داخل برنامه به تنظیمات `Autostart`، `No restrictions` باتری و `Display pop-up windows while running in the background`.

---

## تنظیمات ضروری روی گوشی شیائومی (Redmi Note 13 / HyperOS)

برای عملکرد بی‌وقفه پاپ‌آپ در پس‌زمینه:
1. در تب **«بانک‌ها و تنظیمات»** برنامه، دسترسی پیامک و پاپ‌آپ را تایید کنید.
2. روی دکمه **«فعال‌سازی شروع خودکار (Autostart)»** ضربه زده و تیک برنامه را روشن کنید.
3. در بخش **«مدیریت باتری»** حالت را روی **«No restrictions» (بدون محدودیت)** قرار دهید.
4. در بخش **«مجوزهای دیگر (Other permissions)»** شیائومی، گزینه **«Display pop-up windows while running in the background»** را فعال نمایید.
